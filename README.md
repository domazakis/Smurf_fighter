# Smurf Fighter 🥊

Παιχνίδι μάχης ενός παίκτη (single player) φτιαγμένο **για κινητό**.
Ένα μοναδικό αρχείο `index.html` — χωρίς build, χωρίς εξαρτήσεις, χωρίς internet.

## Πώς παίζεται

Άνοιξε το `index.html` στον browser του κινητού (ή σέρνοντάς το σε έναν desktop browser).
Ο **ΣΤΡΟΥΜΦ** (εσύ) παλεύει με τον **ΚΑΚΟΣΤΡΟΥΜΦ** (υπολογιστής): νικητής όποιος κερδίσει
2 από 3 γύρους. Κάθε γύρος κρατάει 60 δευτερόλεπτα — στη λήξη κερδίζει όποιος έχει
περισσότερη ζωή.

### Χειριστήρια αφής
| Κουμπί | Ενέργεια |
|---|---|
| ◀ ▶ | κίνηση (μπροστά γρήγορα, πίσω πιο αργά) |
| ⬆ | άλμα — δουλεύουν και οι επιθέσεις στον αέρα |
| 👊 | γροθιά: γρήγορη, 6 ζημιά |
| 🦵 | κλωτσιά: πιο αργή αλλά μεγαλύτερη εμβέλεια, 11 ζημιά |
| 🛡 | άμυνα: κόβει ~82% της ζημιάς όσο κοιτάς τον αντίπαλο |

Κάτω-κέντρο υπάρχουν 🔊 ήχος, ⛶ πλήρης οθόνη (κλειδώνει σε οριζόντια όπου υποστηρίζεται)
και ⏸ παύση.

### Πληκτρολόγιο (για δοκιμή σε υπολογιστή)
`←` `→` κίνηση · `↑` άλμα · `J` γροθιά · `K` κλωτσιά · `L` άμυνα · `P` παύση · `Enter` έναρξη

## Τακτική

Ο αντίπαλος μπλοκάρει όταν σε δει να ξεκινάς επίθεση, οπότε το σπαμ γροθιάς τιμωρείται.
Κράτα άμυνα, άσε τον να επιτεθεί και χτύπα αμέσως μετά — η κλωτσιά φτάνει πιο μακριά
από τη γροθιά του. Τρεις δυσκολίες: Εύκολο / Κανονικό / Δύσκολο (αλλάζει ταχύτητα
αντίδρασης, επιθετικότητα και συχνότητα άμυνας του AI, και ανεβαίνει λίγο σε κάθε γύρο).

## Τεχνικά

- Canvas 2D, λογική ανάλυση 800×450, κλιμάκωση σε οποιαδήποτε οθόνη με `devicePixelRatio`.
- Σταθερό βήμα προσομοίωσης 60 Hz με accumulator — ίδια αίσθηση σε 60/90/120 Hz οθόνες.
- Pointer Events με `setPointerCapture`, ώστε να δουλεύουν πολλά δάχτυλα ταυτόχρονα
  (π.χ. κίνηση + επίθεση), και buffer 7 frames στα taps για γρήγορη απόκριση.
- Ξεχωριστή διάταξη για οριζόντια και κατακόρυφη οθόνη, με σεβασμό στα `safe-area-inset`.
- Ήχοι με WebAudio oscillators (μηδέν αρχεία), ξεκλειδώνουν στο πρώτο άγγιγμα.
- Χαρακτήρες, φόντο και εφέ ζωγραφίζονται προγραμματιστικά — καμία εικόνα, ~55 KB σύνολο.
